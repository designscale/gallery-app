## How to deploy to GitHub Pages

1. Go to [github.com](https://github.com) and create a new repository named `gallery-app`
2. Upload the contents of this folder (just `index.html` and `README.md`)
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch → `/ (root)`
5. Click **Save** — your site will be live in ~60 seconds
